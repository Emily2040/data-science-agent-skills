# Evidence Map For Semantic Lineage Mapper

Skill-specific pain point: Teams cannot explain where a metric, feature, or model input came from after it breaks or is challenged.

Skill-specific hypothesis: Lineage mapping combines static extraction with semantic owner questions so blind spots are visible instead of assumed away.

## Skill-Specific Evidence Themes

- Lineage extraction from SQL references, notebooks, pipeline configs, dashboards, and feature lists.
- Manual handoffs and ownerless dependencies are treated as first-class risk.

## Non-Duplication Position

Existing public tools often cover individual operations such as profiling, validation, tracking, orchestration, visualization, or monitoring. This skill is not a wrapper for one tool. It packages the judgment workflow around tool selection, evidence review, risk classification, and audit-ready reporting.
