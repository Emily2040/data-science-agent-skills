# Reddit Infographic Spec: Messy Data Cleanroom

Canvas: 1080x1350 vertical, mobile-readable.

Hero shot: A raw spreadsheet passes through a transparent cleanroom and exits as a versioned, auditable table.

Proof callout: Makes cleaning reviewable instead of magical.

Composition:

- Top 18 percent: crisp title and one-sentence pain statement.
- Middle 42 percent: before/after hero panel showing the transformation.
- Lower 30 percent: 3 to 5 workflow blocks, each with one verb-led label.
- Footer: proof callout and skill name.

Visual rules:

- Use strong contrast and restrained palette.
- Avoid stock photos, tiny text, decorative blobs, and generic AI imagery.
- Keep claims short and evidence-backed.
- Export PNG for Reddit; keep SVG or JSON prompt as editable source if needed.
